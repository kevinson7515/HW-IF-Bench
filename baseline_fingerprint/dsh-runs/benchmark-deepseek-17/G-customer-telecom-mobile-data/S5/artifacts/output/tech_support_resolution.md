## 2. 问题分类与优先级

用户同时存在两个问题，按工作流应**先解决基础连接（无服务），再解决移动数据**：

1. **无服务 / 无连接（Path 1）**
2. **移动数据不可用 → 可能伴随慢速数据（Path 2.1 → Path 2.2）**

关键背景：用户位于法国，处于其归属网络（home network）之外，属于**漫游**场景。这是诊断的首要线索。

## 3. 诊断与处理步骤

### 3.1 无服务排查（Path 1）

按顺序核查以下项，并逐项处置：

1. **状态栏 / 飞行模式 / 网络状态**
   - 若飞行模式开启 → 引导用户 `toggle_airplane_mode` 关闭。
   - 若飞行模式已关闭 → 继续。

2. **SIM 卡状态**（`check_sim_status`）
   - 显示 "Missing" → 引导用户 `reseat_sim_card` 重新插卡，再确认状态为 "Active"。
   - 显示 "Locked"（PIN/PUK 锁定）→ 升级（escalate）至技术支持的 SIM 安全协助。
   - 显示 "Active" → 继续。

3. **APN 设置**（`check_apn_settings`）
   - 若 APN 不正确 → 引导用户 `reset_apn_settings` 重置，并 `reboot_device` 重启生效。

4. **线路挂起（Line Suspension）**
   - 查询该号码对应线路状态。若线路被挂起，按总政策处置：
     - 因欠费账单挂起 → 用户结清欠费后可解除挂起（解除后引导重启设备恢复服务）。
     - 因合同结束日期已过挂起 → **不允许解除挂起**，升级至技术支持。

### 3.2 漫游检查（境外场景，关键步骤）

用户正在法国（归属网络之外），需要确认漫游已启用：

1. 查询该号码对应线路的 **roaming status**。
2. 若线路**未启用漫游** → 按政策**免费为用户启用漫游**（no cost）。
3. 引导用户在手机上确认 **数据漫游（Data Roaming）开关为 ON**：
   - 若为 OFF → 引导用户 `toggle_roaming` 打开。

### 3.3 移动数据排查（Path 2.1）

1. **运行测速**（`run_speed_test`）确认数据连通性。
2. **移动数据开关**：若 `check_network_status` 显示移动数据被关闭 → 引导用户 `toggle_data` 打开。
3. **数据用量核查**：查询该号码对应线路的 **data usage** 是否超过套餐 data limit：
   - 若已超限导致断网，用户选择：
     - 更换套餐（用户已明确**不更换**）；或
     - **补充流量（refuel）**：用户愿意补充 **2GB**（政策允许的单次补充上限为 2GB）。
   - 补充流量前须先**确认单价**（按该套餐的 data refueling price per GB 计算），再应用到该线路。

### 3.4 确保测速为 excellent（Path 2.2）

数据连通后，若测速低于 excellent，逐项优化：

1. **数据节省模式**（`check_data_restriction_status`）
   - 若 Data Saver 为 ON → `toggle_data_saver_mode` 关闭。

2. **网络模式偏好**（`check_network_mode_preference`）
   - 若为 2G/3G → `set_network_mode_preference("4g_5g_preferred")` 切换到含 5G 的模式。

3. **VPN**（`check_vpn_status`）
   - 若 VPN 已连接且性能为 Poor → `disconnect_vpn` 断开。

4. 每一步之后重跑 `run_speed_test`，直至结果为 **excellent**。

1. 关闭飞行模式（若开启）。
2. 重新插卡（若 SIM 显示 Missing）。
3. 重置 APN 并重启（若 APN 不正确）。
4. 打开数据漫游开关。
5. 打开移动数据开关。
6. 网络模式设为 4G/5G 优先。
7. 关闭数据节省模式（若开启）。
8. 断开 VPN（若连接且影响速度）。
9. 解除挂起后重启设备以恢复服务。

## 7. 边界与政策要点

- 用户**不更换套餐**，仅通过补充流量（最多 2GB）解决超限问题。
- 漫游启用为**免费**。
- 若线路因**合同结束日期已过**而挂起，**不能解除挂起**，须升级至技术支持。
- 若 SIM 被 PIN/PUK 锁定，须升级至技术支持。
- 若上述全部尝试后仍无服务或仍无数据，按政策升级（transfer）至人工/技术支持。
