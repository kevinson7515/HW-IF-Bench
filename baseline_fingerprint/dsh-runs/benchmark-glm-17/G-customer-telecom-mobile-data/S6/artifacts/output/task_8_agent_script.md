# Task 8 分步引导话术脚本 — John Smith / 555-123-2002

配合 `output/task_8_resolution_plan.md` 使用。客服一次只说一步、只让客户做一个动作；每步动作后等待客户回报结果再继续。

**开场（识别客户）**

> 感谢您联系客服。我先为您查询账户信息——请问您的号码是 555-123-2002 吗？
> （已提供号码，按电话号码查询即可；如系统要求其他验证方式，再按政策改用客户 ID 或姓名 + 出生日期。）
>
> 查到后核对：账户状态、线路状态、是否有 Overdue 账单、当前数据用量与套餐流量上限、线路是否已开通漫游。

---

## Path 1：无服务

**1.0 状态栏**

> 请您下拉屏幕，看一下手机顶部状态栏现在显示什么图标？特别注意有没有飞机图标，或者"无信号/No Signal"。

**1.1 网络状态 / 飞行模式**

> 请进入 设置 → 网络（或直接查看网络状态），告诉我：
> - 飞行模式是开还是关；
> - 信号强度显示什么。
>
> （若飞行模式是开的）请您把飞行模式关掉，然后再看一下状态栏，信号回来了吗？

**1.2 SIM 卡**

> 请在设置里查看 SIM 卡状态，告诉我显示的是"激活 Active"、"未插入 Missing"还是"已锁定 Locked"。
>
> （若显示未插入）请您关机取出 SIM 卡、重新插好再开机，然后再看一次 SIM 状态是否变为"激活"，以及状态栏是否有信号。
>
> （若显示锁定 PIN/PUK）SIM 安全问题需要专门的技术支持处理，我先帮您把其他能查的都查完。

**1.3 APN**

> 请查看手机的 APN 设置（接入点名称），告诉我显示是否正常。
>
> （若显示不正确）请选择"重置为默认设置"，然后**务必重启手机**，重启后再看状态栏是否有信号。

**1.4 线路暂停（账户侧）**

> 我这边查一下您的线路状态，请稍等。
>
> （若因逾期账单被暂停）您的线路因为有逾期账单被暂停了。我们可以这样处理：
> 1. 我先给您发送这笔逾期账单的付款请求，您在手机上查看付款请求并确认；
> 2. 付款完成后我确认账单状态变为"已支付"；
> 3. 所有逾期账单付清后我为您恢复线路；
> 4. 恢复后**需要您重启手机**才能重新有服务。
>
> （若因合同到期被暂停）很抱歉，合同已到期的暂停我这边无法恢复，需要转接人工客服处理。

## Path 2.1：移动数据不可用

**2.1.0 测速确认**

> 请您在手机上运行一次测速（speed test），把结果告诉我。

**2.1.2 境外漫游（您在法国）**

> 请查看手机的网络状态，告诉我"数据漫游 Data Roaming"这一项是开还是关。
>
> （若关）请您把数据漫游打开，然后再测一次速。
>
> （若开但仍无连接）我这边确认一下您的线路是否开通了国际漫游……您稍等。
> （若线路未开通漫游）我已经为您免费开通漫游，请再测一次速。

**2.1.3 移动数据开关**

> 请查看网络状态里"移动数据 Mobile Data"是开还是关。
>
> （若关）请您把移动数据打开，然后再测一次速。

**2.1.4 数据用量（账户侧）**

> 我这边看一下您这个号码这个周期的数据用量和套餐上限。
>
> （若已超出上限）您的流量已用完，所以数据连接被切断了。可以补充流量：按您的套餐，每 GB 是 [套餐单价]，补充 2GB 一共是 [2 × 单价]。您确认按这个价格补充 2GB 吗？确认后我马上为您加上，然后请您再测一次速。

---

## Path 2.2：速度不是 excellent

**2.2.1 数据节省模式**

> 请查看手机有没有开启"数据节省 Data Saver"模式。
>
> （若开）请把它关掉，然后再测一次速。

**2.2.2 网络模式**

> 请查看手机的网络模式偏好，现在偏好哪种网络（5G/4G/3G/2G）。
>
> （若是 2G 或 3G）请把网络模式改为"4G/5G 优先"，然后再测一次速。

**2.2.3 VPN**

> 请查看手机上是否正在使用 VPN。
>
> （若有且已连接）请断开 VPN，然后再测一次速。
