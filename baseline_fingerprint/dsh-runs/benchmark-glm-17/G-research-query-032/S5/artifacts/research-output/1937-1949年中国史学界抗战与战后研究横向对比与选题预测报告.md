## 一、总览：中国学界1937—1949年研究的建制、规模与格局

### 1.1 学科建制与发展阶段

学界通行以1991年为抗战史学科建制元年：当年1月中国抗日战争史学会成立，9月《抗日战争研究》创刊（[王建朗：《回顾与前瞻：抗日战争研究三十年》](http://jds.cssn.cn/newzxdt/202111/t20211125_5376948.shtml)）。中共党史和文献研究院研究员章百家将改革开放以来40余年的抗战史研究划分为四个阶段（[《关于深化抗战史研究的若干思考》](http://www.1937nanjing.org/xueshujiaoliu/xueshuyanjiu/2026/0722/5744.html)，以下称"章百家文"）：

1. **起步与思想解放阶段（20世纪80年代初—90年代中）**：重评抗战领导权、正面战场、"远东慕尼黑"等禁区命题，考证"田中奏折"真伪等史实；何理《抗日战争史》等初步构建体系。
2. **专题深化阶段（90年代中—2005）**：抗战胜利50周年前后出现第一个成果高峰，军科院三卷本《中国抗日战争史》、中央党史研究室《中华民族抗日战争史（1931—1945）》、王桧林主编"抗日战争史丛书"（近50册）、刘大年主编"中国抗日战争史丛书"（近20册，含《中国复兴枢纽：抗日战争的八年》等）相继问世（[臧运祜：《关于中国抗日战争通史的编纂问题》](http://hrczh.cass.cn/sxqy/zgs/202502/t20250228_5854143.shtml)）。
3. **多元发展阶段（2006—2015）**：抗战损失、日军暴行、战后审判、经济社会变迁等以往被忽视的课题受到重视。
4. **强化提升阶段（2015年至今）**：2015年习近平提出抗战研究"还远远不够"，2016年国家社科基金设立"抗日战争研究专项工程"，2019年近代史研究所设立抗日战争史研究室（臧运祜文）；2017年教育部要求教材全面落实"十四年抗战"概念（[新华网](http://news.xinhuanet.com/politics/2017-01/11/c_1120284611.htm)），2025年抗战胜利80周年前后出现新的成果发布高峰（详见1.4）。

就本报告时段（1937—1949）而言，学界内部的分期意识经历了两次重要扩展：**一次前移**（"八年抗战"改"十四年抗战"，将1931—1937年东北及全国局部抗战纳入整体叙事，东北抗联研究随之升温），**一次后延**（《抗日战争研究》编辑部提出"大抗战史"理念，主张时间上前伸后延、兼顾战后问题；章百家文则明确提出"把解放战争同抗日战争打通来研究"）。1945—1949年部分，长期在"中华民国史"与"中共党史/新民主主义革命史"两个框架下分进，2026年出现解放战争史研究"再出发"的明确动向（见1.6）。

### 1.2 研究队伍：五路大军

- **社科院系统**：近代史研究所（抗战史研究室、《抗日战争研究》《近代史研究》《台湾历史研究》编辑部、中日历史研究中心；王建朗、汪朝光、邓野、徐志民、褚静涛等）、世界历史研究所（二战史、《新编第二次世界大战史》）。
- **高校系统**：南京大学中华民国史研究中心与新中国史研究院（张宪文、张生团队）、西南大学中国抗战大后方研究中心（潘洵）、上海交通大学东京审判研究中心（程兆奇）、华东师范大学历史学系及冷战国际史研究（杨奎松、沈志华）、山西大学中国社会史研究中心（行龙、岳谦厚）、南京师范大学（张连红、严海建）、上海师范大学中国"慰安妇"问题研究中心（苏智良）、北京大学、清华大学、复旦大学、南开大学（李金铮）等。
- **党史系统**：中央党史和文献研究院（章百家等）及地方党史部门。
- **军队系统**：军事科学院军事历史研究部（《中国抗日战争史》《中国人民解放军全国解放战争史》）、国防大学。
- **档案文博系统**：中国第二历史档案馆、国家档案局、侵华日军南京大屠杀遇难同胞纪念馆、侵华日军第七三一部队罪证陈列馆、南京民间抗日战争博物馆。

王建朗称抗战研究已成为近代史研究的"显学"，"研究队伍最为浩大、研究成果最为丰富"的时段（王建朗文）。

### 1.5 成果的领域分布：期刊量化数据

汪海涛对《抗日战争研究》1991—2021年全部文章的主题统计（[《〈抗日战争研究〉30年论文主题探密》](http://jds.cass.cn/xscg/ybwz/202302/t20230209_5587050.shtml)）：**军事史141篇、综述类147篇、日本侵华史123篇、政治120篇、人物114篇、外交113篇、根据地与沦陷区105篇、经济97篇、文化教育96篇、战后审判与战争遗留问题126篇、国防动员59篇、南京大屠杀56篇、社会54篇、华侨台湾27篇、地理交通19篇、救护卫生16篇**。张志一此前对1991—2010年1026篇论文的定量分析显示：社会经济文化教育类占23.38%居首，政治军事类22.73%，日本侵华22.08%，战争遗留问题13.64%，中外关系8.44%，人物7.8%（汪海涛文引）。由此可见：**社会经济文化类已成为成果数量最大的板块；战争遗留与战后审判比重可观；传统军事史在期刊一度式微（受《军事历史研究》等分流）后近年回流；救护卫生、地理交通、华侨台港澳等仍是冷门**。

## 三、横向对比分析

### 3.1 研究领域对比：冷热不均的"板块结构"

| 板块 | 热度 | 主导议题 | 薄弱环节 |
|---|---|---|---|
| 军事史 | 先降后升 | 通史战史、"新军事史"（后勤、编制、兵役、兵工） | 战役战术微观研究、权威抗战战争史专著长期缺位（2015年复旦沙龙结论、杨奎松2016年之问） |
| 政治史 | 经久不衰 | 国共关系、蒋介石、国民党党机器、根据地建政 | 新县制等地方政治制度缺乏权威专书 |
| 根据地史 | 最活跃之一 | 财政货币、动员、日常、组织 | 与大后方/沦陷区的贯通比较不足 |
| 大后方史 | 2011年后新兴热点 | 经济金融工业、轰炸、社会变迁 | 跨区域整合、战后延续性 |
| 沦陷区史 | 相对薄弱 | 伪政权政治史、基层政权 | 社会文化、"灰色地带"、伪政权比较 |
| 经济社会史 | 数量最大 | 统制经济、通胀、难民、灾荒、日常 | 碎片化、宏观整合不足 |
| 暴行史 | 国际关注度最高 | 南京大屠杀、细菌战、慰安妇、轰炸、劳工 | 基本资料已充分发掘，"爆炸性新资料"难现（王建朗语），需精细化与国际化传播 |
| 外交史 | 传统强项 | 中美中苏、大国地位、战后秩序 | 对海外文献的挖掘利用仍是短板（臧运祜） |
| 战后1945—1949 | 明显薄弱、正在升温 | 接收、审判、政争、内战、1949 | 军事本体、国民党内部视角、城市社会心理、制宪国大专书、比较研究（2026年解放战争史论坛共识） |
| 华侨与台胞抗战 | 明显边缘 | 华侨动员、南侨机工、台胞抗日 | 外文史料与侨居地视角几乎空白；台胞专题研究滞后（张秀明2024年述评） |

**横向差异的核心**：抗战段（1937—1945）已形成"整体史"格局并高度建制化，而战后段（1945—1949）长期依附于民国史与党史两个学科框架，缺乏独立建制（无专业期刊、无学会），2026年才出现首届专题学术论坛——**两个时段的研究成熟度呈明显的"梯度落差"**，这既是短板也是空间。

### 3.2 研究视角对比

1. **自上而下→自下而上**：80年代以决策层、大事件、领袖人物为中心；90年代后社会史崛起，"从政治史范式向社会史范式的转变被视为近现代史研究的里程碑"（欧阳恩良：[《谈谈抗日战争史研究的理论与方法》](http://www.xinhuanet.com/politics/2015-11/25/c_128466786.htm)）；近十年进一步下沉到日常生活、身体、情感、物质。
2. **革命史范式 vs 现代化范式 vs 新文化史**：革命性话语（反帝反封建主线）成果最丰但偏重中共与敌后；现代性话语利于整体认识但轻忽救亡主题；后现代话语因解构倾向受批判（欧阳恩良）。学界主流主张"消解非此即彼的范式壁垒"，提出"重振政治史""政治—社会史"等融合方案。
3. **民族复兴框架**：以刘大年丛书《中国复兴枢纽》为源头、八卷本《中国抗日战争史》为集成的"抗战是中华民族伟大复兴的枢纽"叙事，成为学界主导性总体判断（王建朗文）。
4. **国际视角**："东方主战场"论述与全球史视野；"他者视角"（日本对中共的调查、英美对华观察、外国记者报道）成为新增长点（高峰论坛综述、2024年综述）。
5. **区域视角**：根据地—大后方—沦陷区"三大板块"的区域史格局；山西、山东、西南、东北等区域抗战史专题化（高峰论坛综述；潘洵文指出大后方研究"由地方史发展为国际热点"）。
6. **记忆与书写视角**：2014年国家公祭制度建立后，抗战记忆、纪念、历史书写成为学术新维度（李里峰文）。
7. **比较视角**：章百家倡议开展各国"战争体验、记忆与认知"的比较研究，认为这是深化抗战史的重要方向（章百家文）；汪朝光《抗日战争的比较视角与现代意义》亦为例证（高峰论坛综述）。

### 3.3 研究方法对比

- **多边档案互证**已成各领域共同的方法论自觉：外交史用美、俄、日档案（陶文钊、沈志华、鹿锡俊）；政治史用两岸档案与日记（杨天石四度赴胡佛抄录蒋日记；近代史所组织抄录团队）；暴行史用加害方、受害方与第三方档案（南京大屠杀史料集遍赴七国搜集）；战后史用俄档（沈志华主编《俄罗斯解密档案选编》）与审判档案。
- **史料整理工程化、数据库化**：从纸本汇编到"抗战文献数据平台"3500万页公益开放，被学界称为"数据库革命"；罗敏、姜涛同时指出国内数据库在结构化标引、应用模式、复合型人才上的短板（[中国社会科学报](http://www.nopss.gov.cn/n1/2019/0620/c373410-31170697.html)）。
- **口述史**：抗战老兵、大屠杀幸存者、慰安妇与细菌战受害者的抢救性访谈；但研究者自评相对于500余万参战官兵，受访老兵比例太小（[《与历史对话：抗战老兵口述史抢救》](http://www.1937nanjing.org/kanzhanlishi/laobingkoushu/2022/0928/4943.html)）。
- **计量与数字方法**：文献计量（张志一、汪海涛）；经济史的计量分析（通胀、金圆券）；GIS与文本挖掘开始进入（"数智史学"讨论升温：《历史研究》2025年人工智能笔谈、《史学月刊》2025年"数智时代与史学革命"）。**但总体上数字方法在抗战史中的应用仍以"数据库建设"为主，深度分析应用少。**
- **跨学科方法**：政治学（政党组织分析，王奇生）、社会学（动员技术，李里峰、齐小林）、法学（东京审判与国际法，程兆奇、徐持、曹鲁晓）、医学史（细菌战、战时卫生）、环境史（程森冀西河滩地治理）等。
- **微观个案方法**：县域、村庄、个人日记（陈克文、王子壮、黄体润、刘大鹏日记研究）大量涌现，形成"宏观视野下的微观考察"新趋势（2024年综述）。
- **"纪实学术"路径**：刘统以档案加口述重构战役，沟通学界与公众。

### 3.4 理论运用对比

| 理论资源 | 主要运用领域 | 代表性体现 |
|---|---|---|
| 唯物史观/革命史观 | 全领域（主导性框架） | 十四年抗战贯通论述；"两个战场"关系；中流砥柱论（夏春涛2025） |
| 民族复兴/民族解放战争框架 | 宏观叙事、通史 | "复兴枢纽"说；八卷本《中国抗日战争史》 |
| 现代化理论 | 经济史、大后方研究 | 西部开发、工业内迁、"孕育现代化新因素"（八卷本） |
| 战争动员与国家—社会理论 | 根据地、解放战争 | 诉苦、参军、支前、兵役研究（李里峰、齐小林） |
| 政治社会学/组织理论 | 国民党研究 | "弱势独裁党"（王奇生） |
| 冷战国际史/"中间地带"论 | 战后史 | 杨奎松、沈志华、吕迅 |
| 集体记忆理论（哈布瓦赫、诺拉） | 记忆、纪念、书写 | 李里峰文所述新成果 |
| 概念史/新文化史（语言转向） | 观念、阅读、日常 | 黄兴涛、桑兵、李金铮等 |
| 社会性别理论 | 慰安妇、妇女动员 | 苏智良及后继性别维度研究 |
| 国际法理论 | 战后审判 | 程兆奇、徐持、严海建、曹鲁晓 |

**对比性观察**：不同领域理论运用"密度"差异显著——宏观通史领域以民族复兴框架整合；社会文化领域大量借用西方新理论（新文化史、记忆、性别）；政治史与根据地史偏好中层理论（组织、动员、国家能力）；暴行与审判研究则兼具史料实证与国际法理论。学界自我期许是"既务实又就虚"（李里峰），即在实证与理论之间保持平衡；同时以唯物史观为底线反对历史虚无主义（欧阳恩良）。

### 3.5 研究结论对比：共识与分歧

**已成共识的结论**：
1. 正面战场与敌后战场"相互依存、相互支持、缺一不可"的全民族抗战格局（官方与学界表述趋同，[国新办发布会](http://www.scio.gov.cn/xwfb/gwyxwbgsxwfbh/wqfbh_2284/2015n_9477/2015n08y13r/zy_9862/202207/t20220715_188165.html)）；刘大年"国共两个领导中心并存"说经张海鹏阐发渐成共识。
2. 抗战是中华民族伟大复兴的枢纽：近代第一次完全胜利的民族解放战争，奠定大国地位（"四强"、联合国创始国），"为数年后中国社会的巨变准备了条件"。
3. 日军暴行的基本史实与证据链（南京大屠杀、细菌战、慰安妇、无差别轰炸），对日本右翼否认形成学术反制。
4. 中共在敌后的动员绩效与组织能力是其战争胜负与政权兴替的关键变量（李金铮、齐小林、李里峰等微观研究的共同指向）。
5. 战时工业内迁保存了工业基础并重塑西部经济地理，但国家资本垄断与民营经济困境并存（大后方研究）；田赋征实缓解军粮危机而加重农民负担（郝银侠）；华侨捐款逾13.2亿元国币、侨汇95.74亿元国币，构成抗战的"海外战场"（张秀明述评引数据）。

**仍存分歧或竞争的解释**：
1. **抗战起点与分期**："十四年抗战"已成教学与政策标准，但1931/1937的学理边界、局部抗战与全面抗战的衔接仍在讨论（章百家指出贯通书写"需要更宏观的视野"）。
2. **政协与和平的可能性**：邓野认为政协决议缺乏武力基础、注定顿挫（"民国政治的逻辑"）；汪朝光强调民主化契机的特殊国内外条件与多因性——两说构成张力。
3. **国民党失败原因**：结构性解释（接收腐败"劫收"、派系倾轧、经济崩溃、军事失误）已成主流；单一"腐败论"被多因论取代（对照易劳逸"毁灭的种子"结构性论、胡素珊民心论）。
4. **中共胜利的解释**：李金铮归纳土地集中—贫困论、社会经济改革动员论、民族主义论、组织渗透论四种路径并指出单一解释均不充分；杨奎松突出国际（苏联）因素；沈志华强调斯大林政策转变对东北战局的影响；微观动员研究补充"民心"命题。
5. **抗战与中国现代化**："中断论"与"西迁促进论"并存；八卷本取"孕育和积累现代化的新因素"的折中表述。
6. **沦陷区与"协作"问题**：从"汉奸框架"到政治史、思想史、社会史的再审视（李志毓），与国际学界"灰色地带"研究的对话尚待展开。
7. **数字与评价之争**：东京审判与南京审判对大屠杀死难人数的表述不一，《南京大屠杀全史》承认差异而不再强行弥合；南侨机工伤亡"三个三分之一"说被夏玉清、陈达娅以档案数据质疑；侨领胡文虎评价在"汉奸说"与"民族气节说"之间长期争论（张秀明述评）；战时通胀成因存在货币发行说与结构性因素之辩。

## 四、总体评估：优势与短板

**优势**：（1）建制完备——学会、专刊、专项工程、研究室、青年学者研讨会、年度综述制度俱全；（2）史料经历"数据库革命"——平台公益开放获国际学界称誉；（3）领域覆盖齐全并不断扩张——从战争史到整体史、从精英到日常、从中国到全球；（4）梯队与平台厚实——专题丛书（"抗日战争专题研究"55卷）、重大成果发布机制与国际对话（中日共同历史研究、两岸论坛、九江国际会议）并行。

**学界自评的短板**（这是选题预测的依据）：
1. **碎片化**：微观与宏观逻辑联系被斩断，"只见树木不见森林"、史料圈地不共享（欧阳恩良）；章百家直言担心"研究越来越细化导致认知碎片化"。
2. **重复与解析不足**：文献刊布进步巨大但专业整理与学术解析薄弱、重复刊布，"拳头作品"缺乏；海外文献挖掘利用是"一大短板"（臧运祜）。
3. **军事史实证不足**：长期缺乏分量的抗战战争史专著（2015年复旦沙龙结论；杨奎松2016年"抗战史应重视战争史研究"之问）。
4. **战后史薄弱**：通史多止于1945年，臧运祜建议抗战通史专设"战后"卷（战争遗留、中日关系、纪念与记忆）；解放战争史2026年才首设专题论坛，"研究还有很大潜力"（论坛共识）。
5. **冷热不均**：沦陷区、东北义勇军、伪军汉奸、华侨台港澳、救护卫生等偏冷；暴行研究"很难出现新的爆炸性资料"（王建朗），需转向精细化与国际化传播；华侨研究外文史料与侨居地视角几乎空白（[张秀明述评](http://www.1937nanjing.org/xueshujiaoliu/xueshuyanjiu/2025/1105/5660.html)）；2018年中国抗日战争史学会年会上，桑兵直言沦陷区研究"严重失位"、大后方研究对西北地区关注不够（[会议报道](http://jds.cssn.cn/newzxdt/202101/t20210128_5298073.shtml)）；西北大后方研究远逊于西南，大后方与沦陷区、根据地三板块的互动研究薄弱。
6. **数字人文深度不足**：数据库建设强、数据密集型研究弱（罗敏、姜涛）；口述覆盖面小。
7. **比较研究缺位**：跨国别、跨战场的战争体验与记忆比较刚被倡导（章百家）。
8. **暴行研究"重史料轻理论"**：战争暴力机制、跨国比较与和平学理论化不足，是孙宅巍对该领域的自我诊断（[《南京大屠杀研究的学术演进与未来展望》](http://www.1937nanjing.org/xueshujiaoliu/xueshuyanjiu/2026/0722/5752.html)）。

## 五、未来最具研究潜力与空间的选题预测

综合上述"领域冷热—视角演化—方法缺口—学界自评"四个维度，预测以下三个选题最具研究潜力与研究空间（按把握度排序）。

### 选题一：1945—1949年"从战争到国家重建"的整体研究（打通抗战史与解放战争史的过渡期研究）

**选题定位**：以"抗战的终结与善后"为入口，把1945—1949年作为一个独立的"战争—重建—政权更替"过渡时段整体研究，回答"抗战如何收场、战后中国如何重建、重建为何走向内战与1949"。

**选题依据**：
- 这是学界自评最明确的结构性空白：通史多止于1945（臧运祜建议专设"战后"卷）；章百家明确提出"把解放战争同抗日战争打通来研究"；2026年首届解放战争史研究学术论坛形成"在大历史观下把握抗日战争史、解放战争史和新中国成立初期史的内在联系"的共识；中国社科报以"解放战争史研究持续推进"为题报道该领域升温。
- 80周年节点后研究重心自然后移；"抗日战争专题研究"丛书已将"日军暴行与审判"、战后审判纳入框架，但接收、复员、经济重建、社会心理等战后课题远未饱和。
- 史料条件已全面成熟：接收与敌伪产业档案（中国第二历史档案馆）、国民政府审判档案集成与东京审判全译本（2026年首发）、俄档（沈志华主编12卷《俄罗斯解密档案选编》）、蒋介石日记、地方档案与报刊（抗战文献数据平台）。

**核心研究问题**：战争终结机制与受降复员；接收"劫收"的政治经济学；审判、惩奸与历史正义的建立；日俘日侨遣返；战后通胀与金圆券；"胜利的代价"——胜利后城市中产、知识分子与普通民众的心理与选择；中共从战时体制（根据地、动员机制）向全国执政体制的转型；美苏政策转变与中国内战的国际起源。

**方法与理论**：多边档案互证+地方档案+量化（通胀、物价）；可引入战争终结（war termination）、国家重建、政权更替比较研究（与战后欧洲、日本的战后处置比较），实现章百家倡导的比较视角。

**预期突破**：将"抗战遗产"概念化，解释1949年结果中战时因素（组织、财政、动员、人心、国际）的连续性机制；产出贯通性的战后通史或系列专著，填补"拳头作品"空白。

**风险与对策**：内战叙述的政治敏感性——应在既有"两种历史框架"的交集处选题（审判、接收、经济、社会），以档案实证立论；团队上宜采取"民国史+党史"双背景合作。

### 选题二：战时基层社会与日常生活的"三大板块贯通"微观—整体研究（1937—1949年"战争中的普通人"）

**选题定位**：以普通人的生存、负担、迁徙、情感与选择为中心，在根据地、大后方、沦陷区三大板块之间做贯通比较的日常生活史，并延伸到1946—1949年内战时期，回应"碎片化"批评。

**选题依据**：
- 社会史成果数量第一（占比23.38%），但碎片化批评也最烈——学界共识是"微观考察"必须与"宏观视野"结合（2024年综述语），这正是本选题的差异化定位。
- 前沿号召明确：黄道炫"倾听静默的声音"（流亡迁徙史、灾荒被难史、民众负担史、女性史、民众观念史）；宋弘"革命日常史"；李里峰系统梳理的情感史、身体史、物质文化史、阅读史等新路径，指出抗战史"持续创新动力将主要来自学科交叉融合"。
- 空白明显：根据地日常生活研究已起步，但**沦陷区与大后方普通人的日常远未展开；内战时期（1946—1949）的日常生活几乎无人研究**；情感史、身体史刚起步。
- 史料基础雄厚：私人日记（陈克文、王子壮、黄体润、刘大鹏、贝铁德《上海纪事》等已在学界使用）、家书账本、口述抢救、地方档案与报刊（平台可全文检索《大公报》《申报》等千余种报刊）。

**核心研究问题**：战时民众负担与生存策略；沦陷区"灰色地带"普通人的协作、抵抗与生存伦理；奔赴后方的青年流亡体验；战时家庭、婚姻与女性经验；通货膨胀下的城市中产日常生活；战争创伤、情感与心态史；内战时期国统区与解放区民众日常的对比。

**方法与理论**：民间文献+口述+微观个案+跨板块比较；借鉴日常生活史、情感史、物质文化史、性别史与记忆理论，同时以"总体战""战争社会学"重建微观与宏观的联结（战争如何重塑国家—社会关系）。

**预期突破**：建立"战争中的普通人"的中层分析框架，把三大板块与两个时段（抗战/内战）打通；在史料上形成民间文献的系统整理与数据库化，兼具填补空白与回应碎片化批评的双重价值。

### 选题三：数据密集型抗战史——基于3500万页平台与多源档案的量化重建

**选题定位**：把"数据库革命"推进为"研究范式革命"，利用抗战文献数据平台、GIS与计量方法，对战争损失、人口流动、经济变动、舆论传播进行系统的量化重建，产出可重复检验的实证结论。

**选题依据**：
- 基础设施世界级但应用严重不足：平台3500万页永久公益开放，被海外学者视为"福利"；而学界自评短板恰在"结构化标引、应用模式、复合型人才"（罗敏、姜涛）。**基础设施与应用之间的落差就是研究空间。**
- 方法论氛围已至："数智史学"讨论升温（2025年《历史研究》人工智能笔谈、《史学月刊》"数智时代与史学革命"）；经济史已有计量示范（通胀与金圆券实证、文献计量）。
- 政策需求明确：抗战损失调查的官方数字（如伤亡3500万）需要学术化、精细化的实证支撑；纪念政治与对外话语权斗争（对日右翼否认、国际二战叙事重构）都要求"用数据说话"。

**具体可做的课题**：①抗战人口伤亡与财产损失的分区、分类再估算与不确定性区间；②重庆等地日军无差别轰炸的时空GIS重建与损失量化（可与潘洵团队衔接）；③战时物价、货币与通胀数据库建设及机制分析（衔接金圆券研究）；④根据地—国统区—沦陷区三区报刊的文本挖掘与概念/舆情传播分析；⑤难民与人口内迁的量化流动史；⑥审判案例数据库与量刑统计。

**预期突破**：使中国抗战史从以定性叙事为主转向"定性+定量"双重论证，在战争损失、经济崩溃、舆论动员等议题上产出国际可对话的实证成果；并为政府纪念叙事与对日历史话语权提供坚实数据支撑。

**风险与对策**：史料偏差与数据质量需史学考订先行（坚持"数据与史学"互证）；需要历史学+统计学+计算科学的复合团队（恰是学界公认短板，早布局者先得）；须避免"唯量化"，与李金铮等对量化史学的反思保持对话。

### 备选方向（潜力次于上述三者，供参考）

- 华侨抗战与跨国支援网络（拉纳·米特早年指出华侨贡献、国际组织活动、战时社会福利等待开拓领域，至今仍具参考价值；张秀明2024年述评证实其边缘地位）；
- 沦陷区"灰色地带"与协作研究（与国际学界对话，填补薄弱板块）；
- 抗战记忆史与纪念政治（国家公祭制度、纪念馆、教科书、口述抢救的学术化）；
- 战时环境史与医疗社会史（已有个案、无系统成果）；
- 东北抗战与东北抗联史（"十四年抗战"框架下的前移红利）；
- 蒋介石及国民党军政系统的"档案深描"（"后日记时代"转向档案本体）；
- 中外战争体验与记忆的比较研究（章百家倡议）。
