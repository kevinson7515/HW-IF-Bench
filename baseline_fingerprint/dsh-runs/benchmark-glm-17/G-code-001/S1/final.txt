修复完成并已验证。所有检查通过，原先的 `IndexError` 不再出现。

## 缺陷原因

`text.split()` 对空字符串或纯空白字符返回空列表 `[]`，而 `parse_text` 未做检查直接访问 `tokens[0]` 和 `tokens[1]`，导致 `IndexError: list index out of range`。

## 修改内容（仅限 `parse_text` 函数体）

```python
# 空输入或纯空白字符时，command 与 argument 均为 None
if not tokens:
    return {"command": None, "argument": None}

command = tokens[0]
argument = tokens[1] if len(tokens) > 1 else None
```

- 空输入 / 纯空白字符：返回 `{"command": None, "argument": None}`，保持返回类型和键不变，调用方无需处理异常
- 单词输入：`argument` 为 `None`（原来 `tokens[1]` 同样会抛 `IndexError`，属同类缺陷，一并修复）
- 两个及以上 token：行为与原来完全一致（`command` 取第一个词，`argument` 取第二个词）

按约束要求，函数的示例入口（`__main__` 块）、文档字符串和其余代码均未改动；仅删除了函数体内描述已修复缺陷的两行过时注释。
