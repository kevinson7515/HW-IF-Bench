## 修改内容

**`src/core/parser.py` — 仅修改触发缺陷的 `parse_text` 函数：**

```python
def parse_text(text: str) -> dict:
    """
    解析文本输入，返回命令与参数；缺失的 token 对应字段为 None。
    """
    # split() 在面对空字符串或纯空白字符时，会返回一个空列表 []
    tokens = text.split()

    # tokens 可能为空或不足两个元素，直接索引会抛出 IndexError；缺失字段取 None
    command = tokens[0] if tokens else None
    argument = tokens[1] if len(tokens) > 1 else None
```

- 空输入（`""` 或纯空白）时 `tokens` 为空列表，原先 `tokens[0]` 直接抛 `IndexError`；现在按存在性取值，缺失字段为 `None`。
- 同一函数内 `tokens[1]` 也做了同样的保护，单个 token 不再越界。
- 文件末尾的示例入口（`__main__` 块）逐字保持不变。
