# 1937—1949年中国历史学界研究现状梳理、横向对比与未来选题预测

> 说明：本报告以中国历史学界（含大陆学界为主，兼及台湾与海外中国学界的参照）对1937—1949年（全面抗战 + 战后/国共内战过渡期）的研究为对象，基于近年多篇权威学术史综述与代表性论著完成。核心依据见文末【主要依据文献】。

---

## 一、总体脉络：从"战争史"到"整体史"，再到"新文化史与全球史"

1937—1949年这段历史的研究，其学科建制起点可以1991年《抗日战争研究》创刊、中国抗日战争史学会成立为标志。据王建朗（中国抗日战争史学会会长）总结，三十年抗战史研究已从"主要关注军事史"发展为"抗日战争时期整体史研究"，抗战史成为近代史诸时段中"研究队伍最为浩大、成果最为丰富"的一门"显学"。其演进大致分三个阶段：

1. **1980年代（学科初创）**：拨乱反正、思想解放，聚焦宏大全局性问题（抗战领导权、正面战场评价、废除不平等条约后的半殖民地性质、有无全国性战略反攻等）与关键史实考证（"田中奏折"真伪等），学术争鸣热烈。
2. **1990年代（专题化、通史化、成熟繁荣）**：专题研究精细化，通史与大型丛书（军事科学院《中国抗日战争史》3卷、中共中央党史研究室《中华民族抗日战争史》、抗战史学会"中国抗日战争史丛书"等）相继面世，形成独立学科体系。
3. **21世纪以来（整体史 + 范式多元）**：社会史大规模渗透→"新革命史"兴起→"新文化史"（记忆史、概念史、阅读史、情感史、日常生活史）→全球史/跨国史，并伴随史料数据库建设（"抗战文献数据平台"2018年上线，截至2025年逾6000万页）的重大基础设施变革。

一个关键的结构性判断贯穿始终：**1937—1949这一段，长期被"1949年革命胜利"这一后置视角所支配，抗战常被简化为"革命胜利的前奏"**（[拉纳·米特2025年文](http://jds.cass.cn/xscg/xslw/202601/t20260130_5971442.shtml)）。因此学界近年的核心转向之一，正是把抗战乃至战后过渡期当作**具有独立历史意义的转型阶段**来审视，而非革命的注脚。

## 二、代表性成果与学术阵营整理

### （一）抗战时期（1937—1945）

**1. 通史与整体研究**
- 步平、王建朗主编《中国抗日战争史》（全八卷，2019—2020），把抗战放入世界大环境与战后长时段考察，强调"中华民族复兴枢纽"定位。
- 张宪文《中国抗日战争史(1931—1945)》；金冲及《二十世纪中国史纲》抗战部分。

**2. 政治史／国共关系／军事史（传统主干领域）**
- 刘大年提出、张海鹏系统论述的**"国共分别领导抗战"**已成学界共识，领导权之争基本尘埃落定（[王建朗2021年文](http://jds.cssn.cn/newzxdt/202111/t20211125_5376948.shtml)）。
- 金冲及、杨天石、黄道炫、邓野等对国共关系与重大事件（皖南事变、联合政府口号等）的实证重构。

**3. 社会史与"新革命史"（范式转换的主力）**
- 黄道炫《张力与限界：中央苏区的革命(1933—1934)》（方法论范式示范）、其抗战根据地的"权力下探与社会形塑"系列；
- 王奇生《党员、党权与党争：1924—1949年中国国民党的组织形态》；
- **李金铮**（2008年首倡"新革命史"）将阅读史、环境史、生活史引入根据地研究；
- 应星等对"新革命史"理论的系统阐释。

**4. 外交史／国际关系史**
- 王建朗、陶文钊、牛军等，重估美英苏援华、中国大国地位获得（"四强"、联合国安理会常任理事国）与战后秩序参与。

**5. 沦陷区／伪政权／汉奸研究（相对薄弱但近期升温）**
- 臧运祜等对沦陷区的总体性思考（[臧运祜文](http://jds.cass.cn/xscg/xslw/202602/t20260203_5972035.shtml)）；伪满、汪伪政权个案研究较多，其他沦陷区偏弱。

**6. 日军暴行与战争遗留问题**
- 南京大屠杀（《南京大屠杀史料集》72卷、《南京大屠杀全史》3卷）、慰安妇、强征劳工、细菌战化学战、战犯审判——"存史资政"的主阵地，成果多、社会影响大。

### （二）战后／国共内战（1945—1949）

- 汪朝光《1945—1949：国共政争与中国命运》（2010），战后国共政争—内战的政治史代表作。
- 邓野《联合政府与一党训政：1944—1946年间国共政争》（2003）、《民国的政治逻辑》《蒋介石的战略布局(1939—1941)》——以政治学方法破解民国政治逻辑。
- 杨奎松《失去的机会？——战时国共谈判实录》《国民党的"联共"与"反共"》《中华人民共和国建国史研究》——国共关系与冷战史路径。
- 金冲及《转折年代：中国的1947年》。
- 海外：胡素珊（Suzanne Pepper）《中国的内战》、方德万（Hans van de Ven）《战时中国》、米特（Rana Mitter）《被遗忘的盟友》等。

**结构性观察**：战后（1945—1949）一侧，成熟成果**高度集中在国共两党高层政治—军事博弈**（谈判、决战、战略布局），而**社会史、地方史、日常史、光复区/沦陷区的转型实态、善后救济与国际组织**等层面明显薄弱——这是后文预测选题的重要依据。

## 三、横向对比分析（研究领域、视角、方法、理论、结论）

### （一）研究领域对比

| 领域 | 成熟度 | 特征 |
|---|---|---|
| 政治史／国共关系 | 高度饱和 | 宏观权威意见已形成，"主架构难再出新声"，转向支线实证 |
| 军事史 | 有基础、有空白 | 从"战略决策"下沉到编制、后勤、兵役、参谋、兵工等"能不能打"问题 |
| 外交史 | 较充分 | 中美英苏德关系重估完成，转向"战后秩序参与" |
| 经济史 | 有基础 | 财政、金融、盐政、粮油、工矿等分项细密，但整体性理论不足 |
| 社会史 | 最繁荣 | 成果数量列各领域之首，从高层转向中下层 |
| 根据地史 | 高度成熟 | 陕甘宁、华北诸根据地细密，但比较研究不足 |
| 大后方研究 | 2011年后繁荣 | 有组织化（重庆大后方中心），起步晚但进展快 |
| **沦陷区研究** | **薄弱** | 日、伪、国、共多力量交织，复杂性高，成果相对少 |
| 战后(1945—49)社会面 | **明显空白** | 高层政治军事成熟，社会转型/接收/复员/救济薄弱 |
| 记忆史/情感史/生活史 | 起步期 | 新文化史引入后快速升温，但立项与研究总量仍不足 |
| 环境史 | 萌芽期 | 李金铮《中共抗战的生态环境解释》开风气，起步阶段 |
| 全球史/跨国史 | 起步期 | 西方学界方兴未艾，国内跟进中 |

（分类统计可参考[汪海涛对《抗日战争研究》30年论文的16主题梳理](http://jds.cass.cn/xscg/ybwz/202302/t20230209_5587050.shtml)：政治120篇、军事141篇、经济97篇、文化教育96篇、外交113篇、社会54篇、日军暴行123篇、战争遗留/审判126篇等。）

### （二）研究视角对比

- **自上而下（精英政治/军事决策）** → 传统主导，抗战政治史、战后国共博弈即属此类。
- **自下而上（底层民众、普通士兵、女性、难民）** → 社会史与"新革命史"的核心转向，黄道炫主张"倾听静默的声音"。
- **中国—国别 → 全球/跨国** → 从"中国抗战"到"世界反法西斯东方主战场"、全球史视野下的比较（傀儡政权比较、跨国知识网络）。
- **事件中心 → 结构/长时段** → 从重大战役、重大会议，转向制度、组织、社会结构的长期变迁。
- **国共两党中心 → 多中心/灰色地带** → 沦陷区、伪军、汉奸、会道门、地方实力派、华侨、在华外人等"非两党叙事"主体进入视野。

### （三）研究方法对比

| 范式 | 核心方法 | 代表 |
|---|---|---|
| 传统革命史 | 档案考据 + 政治叙事 | 党史/军史部门 |
| 现代化范式 | 长时段比较、量化 | 张宪文等 |
| 新革命史 | 社会史方法 + 实证微观，"回归历史学轨道" | 李金铮、黄道炫、王奇生、应星 |
| 新文化史 | 记忆/概念/阅读/情感/物质文化分析，意义阐释 | 李里峰所综述一批青年学者 |
| 全球史/跨国史 | 多国档案互证、跨国比较、跨国网络 | 方德万、米特等海外学者 |

**方法论上的三大基础设施性变化**：① **多语种档案互证**（日文、英文、俄文、法文档案的系统引入）；② **大规模史料数据库**（抗战文献数据平台6000万页、满铁/东亚同文书院调查资料影印）；③ **民间文献与口述史料**（日记、书信、笔记、照片、地方争讼材料、口述史）的大规模使用——这是新文化史、日常生活史得以落地的物质前提。

### （四）理论运用对比

- **革命史范式**（阶级斗争、统一战线、党的领导）→ 长期主导，但解释力在"纵深观察近代社会"时显局限。
- **现代化范式**（民族国家建构、现代化进程）→ 作为革命史范式的补充与对话方。
- **"新革命史"** → 反思传统革命史观与现代化史观，主张"回归历史学"，用社会史、微观史方法重新激活革命史（[学术史综述](http://xb.xynu.edu.cn/cn/article/pdf/preview/10.3969/j.issn.1003-0964.2019.01.026.pdf)）。
- **新文化史理论**（"语言学转向"、福柯/格尔茨/诺拉"记忆之场"、哈布瓦赫集体记忆、科塞勒克概念史、夏蒂埃阅读史）→ 近年来最活跃的理论增长点（[李里峰2025年文](http://www.1937nanjing.org/xueshujiaoliu/xueshuyanjiu/2025/1217/5730.html)）。
- **全球史/跨国史理论**（入江昭跨国史、帝国竞争框架、比较法西斯/傀儡政权）→ 尤其海外学界的前沿。
- **跨学科理论**（政治学政治文化分析、社会学集体记忆、人类学象征仪式、传播学接受理论、环境史生态分析）→ 李里峰指出"持续创新的动力将主要来自学科交叉融合"。

### （五）研究结论对比（若干已成共识或仍在争鸣的结论）

- **已成共识**：国共分别领导抗战（刘大年—张海鹏）；美英苏援华与中国大国地位获得；国民党正面战场的历史作用（已获国家领导人讲话确认）。
- **范式性重估**：抗战从"革命胜利前奏"→"中华民族复兴枢纽"的再定位。
- **仍在深化/有争议**：抗战伤亡与损失数据（伤亡比、财产损失精确性）；"战略反攻阶段"有无之争；国共力量对比在抗战中悄然逆转的机制解释；战后国民党军事失利的原因辨析（汪朝光）。
- **新文化史带来的"结论形态"变化**：从追求"唯一真实结论"转向呈现"意义的建构性"——记忆如何被塑造、概念如何被争夺、创伤如何被书写（如谢任《陷都政治》、黄兴涛《重塑中华》对"中华民族"观念生成的考察）。

## 四、未来最有研究潜力与空间的2—3个选题

综合"现有成果饱和度高 vs 低""史料可及性""方法论工具是否成熟""国际对话空间""现实关切"五条标准，我预测以下三个选题最具潜力（前两个确定性最强，第三个作为平行选项）：

### 选题一：战后1945—1949"过渡期"的地方社会与治理实态——接收、复员、光复区与国际善后救济

**为何最有潜力：**
- **结构性空白**：1945—1949的研究长期被"国共高层政争—内战"叙事垄断，社会史、地方史严重缺位。米特明确指出"1945年战后初期阶段与战争后续问题日益受到重视"，且"战后亚洲研究总体单薄"（[米特文](http://jds.cass.cn/xscg/xslw/202601/t20260130_5971442.shtml)）。
- **已现突破口但远未展开**：国民政府"接收"（劫收）的腐败、沦陷区/光复区（东北、台湾、华北、华南）政权的"光复—接管—秩序重建"、复员军人安置、行政院善后救济总署（CNRRA）与联合国善后救济总署（UNRRA）的工作、战后审判与"惩奸"、城市与乡村的经济崩溃（法币崩溃、通胀、米荒）——都是既有史料可支撑、但系统研究稀缺的题目。
- **理论/方法优势**：可嫁接"国家治理、社会治理、边疆治理"这一正受国家社科基金力推的前沿（[把增强2025年文](http://jds.cssn.cn/xscg/xslw/202601/t20260105_5968046.shtml)），并可借"国际组织—国家重建"的全球史视角（UNRRA、联合国）直接进入国际对话。
- **史料可及**：抗战文献数据平台、《抗日战争档案汇编》（1000册规划）、各级档案馆战后档案、中研院近史所档案。

**具体可做方向**：某一大城市或省区的"接收—复员—治理"个案；台湾光复初期的米荒、二二八前夜的治理实态（已有[台湾米荒研究](https://www.mh.sinica.edu.tw/MHDocument/PublicationDetail/PublicationDetail_1607.pdf)可示范）；善后救济总署的区域实践与国际合作。

### 选题二：抗战时期普通民众的"日常生活史 × 情感史 × 记忆史"——士兵、女性、难民与儿童

**为何最有潜力：**
- **多重权威指向同一方向**：王建朗（未来展望之"沦陷区日常实态"）、李里峰（记忆/纪念/情感/日常四大新趋向）、把增强（"记忆史研究不断升温""生活史从幕后走向台前""普通民众、女性、人性的被发现"）、米特（"记忆"主题将日益成为基石，老兵凋零倒逼口述抢救）几乎一致指向此处。
- **方法论已成熟、门槛已降低**：新文化史的理论工具（集体记忆、情感史、物质文化史、阅读史）已被系统引入并示范；日记、书信、口述、照片等民间文献与数据库为底层/女性/儿童/难民发声提供了前所未有的条件。
- **与"大抗战史"的合法性高度契合**，且具备极强的跨学科（口述史、人类学、传播学、医学史/创伤研究）与国际比较空间（可与欧美二战女性史、创伤记忆史相互参照）。

**具体可做方向**：士兵（国、共、日、伪四方）的日常与身体（卫生、婚恋、闲暇——李金铮已点题）；女性战争体验与记忆（潘以红《这不仅是男人的战争》为海外示范）；难民/难童的迁徙、创伤与记忆建构；某一地区民众战争记忆的口述史抢救与"记忆之场"分析。

### 选题三（平行选项）：全球史/跨国史框架下的"战时中国"——跨国知识网络、战时科学与国际组织

**为何值得并列：**
- 米特列举的西方四大新趋势中，"全球史视野""战时社会史""战时科学""战后初期与国际组织"独占其三，且明确指出这是**打开国际学术对话、改变中国抗战在世界二战叙事中边缘地位**的关键路径（[米特文](http://jds.cass.cn/xscg/xslw/202601/t20260130_5971442.shtml)）。
- 国内学界亦在倡导"以全球史观深化中共抗战史研究"（[李翔文](https://www.theorychina.org.cn/c/2026-03-19/1542971.shtml)）、"东方主战场"话语建构。
- **代表议题**：战时中美合作与"战时科学"（地质学、防疫、育种——翁文灏等知识网络）；国际联盟/UNRRA/联合国与中国；华侨跨国网络与南洋；中国抗战与其他反法西斯战场的比较（傀儡政权比较、帝国竞争框架下的全球叙事）。

**需注意的约束**：这一方向**对多语种档案能力与跨国协作要求最高**，且国内档案开放度下降、国际合作"步履维艰"（把增强明言难点）构成现实瓶颈，因此确定性略低于前两者，可作为与国际接轨的"第二曲线"选题。

---

## 五、简要结论

1. 1937—1949研究已形成"政治—军事—外交主干高度成熟、社会史与根据地史繁荣、沦陷区与战后社会面相对薄弱、新文化史与全球史正在兴起"的**梯度格局**。
2. 横向看，研究正在经历**三重位移**：从精英到平民、从国别到全球、从"求真"到"虚实结合"（意义建构）。理论工具上"新革命史"完成了对传统范式的反思，"新文化史"正在成为最活跃的增量。
3. 最具潜力的选题，共同特征是：**落在"成熟领域之外的灰色地带 + 史料可及 + 方法已就绪 + 有国际对话接口"**。据此，我优先推荐**"战后1945—1949过渡期的地方社会与治理实态"**与**"抗战民众的日常生活—情感—记忆史"**两个选题，并将**"全球史/跨国史框架下的战时中国"**作为第三平行选项。
