## Changes made

### 1. `astropy/units/quantity.py`
- Added `from astropy.utils.compat import NUMPY_LT_1_20, NUMPY_LT_1_22` import.
- `var`/`std`/`mean`: each now defined twice under `if NUMPY_LT_1_20` (no `where`) vs `else` (keyword-only `*, where=True`), passing `where` through `_wrap_function`.

- `where = ~self.mask & where` (mean/any/all) and `where_final = ~self.mask & where` (var/std), so user `where` is combined with the mask.

### 3. `astropy/units/tests/test_quantity_array_methods.py`
- Extended the compat import to `NUMPY_LT_1_20, NUMPY_LT_1_21_1, NUMPY_LT_1_22`.
