# 中国学界 1937–1949 年（抗战及战后）研究综述与横向对比

## 一、总体格局：从"显学"走向"整体史"与"三大体系"建设

抗战史研究是20世纪80年代以来中国近现代史中成果最丰、组织化程度最高的"显学"之一。其发展可概括为三个阶段特征：

1. **奠基期（1980s–1990s）**：以军事史、政治史为主，围绕"两战场关系""抗战起点""中共中流砥柱作用"等核心命题展开，代表工程是通史性抗战史著作的编纂。
2. **拓展期（2000s–2015）**：研究领域从军事政治向社会、经济、文化、外交、区域大幅扩展，史料整理（档案、口述、报刊）与数据库建设起步。
3. **深化与体系化期（2015抗战胜利70周年至今）**：在纪念节点推动下，学界明确提出构建抗战史"三大体系"（学科体系、学术体系、话语体系），研究呈现"整体史"取向，并大规模引入新文化史、全球史、数字人文等跨学科方法。

标志性成果包括：步平、王建朗主编《中国抗日战争》（全八卷，社科文献出版社2019）；张宪文主编《中国抗日战争史》；杜继东、吴敏超主编《当代中国抗日战争史研究（1949—2021）》（中国社会科学出版社2025，对70余年学术史做系统总结）；以及"抗日战争与近代中日关系文献数据平台"等基础设施。核心平台为社科院近代史所《抗日战争研究》期刊、抗战史研究室、中国抗日战争史学会。

## 二、研究成果的横向对比分析

### （一）研究领域：从"三分格局"到多板块并进

| 板块 | 主要议题 | 代表力量/成果 |
|---|---|---|
| **军事史** | 正面战场22次会战、敌后游击战、两个战场关系、远征军 | 两个战场关系从"孰主孰次"争论走向"相互依存、缺一不可"的共识（王建朗等） |
| **政治史** | 国共关系、统一战线、根据地政权建设、沦陷区伪政权 | 中共抗战史"学术化"（黄道炫、杨奎松等"新革命史"取向） |
| **外交/国际关系** | 中美苏日、东方主战场、战后秩序、开罗/波茨坦会议 | 全球史观下"世界反法西斯战争东方主战场"叙事重塑 |
| **经济史** | 战时财政金融、通货膨胀、大后方/沦陷区经济 | 通胀与"国民党政权失败起点"（柯博文等）的讨论 |
| **社会史** | 大后方、沦陷区、根据地社会；灾荒、难民、人口 | 西南大学"抗战大后方研究"（潘洵）成为新热点 |
| **文化/思想史** | 知识分子、教育内迁、"中华民族"观念 | 黄兴涛《重塑中华》、概念史研究 |
| **记忆史/新文化史** | 纪念、记忆、创伤、概念史、阅读史、情感史 | 李里峰《新文化史与抗日战争研究的新趋向》（《抗日战争研究》2025年第3期） |
| **专门史** | 医疗史、女性史、口述史、生态/环境史 | 欧美学界带动的"视线下移"（王毅、石瑶述评） |
| **战后处置** | 受降接收、审判、遣返日侨俘、内战爆发、金圆券崩溃 | 相对薄弱，是公认的"研究空白" |

**对比结论**：大陆学界强项在中共革命史、根据地、大后方与史料整理；欧美学界强项在"普通人的战争经验"下沉、医疗/女性/记忆史与全球协作叙事；二者正在形成对话与互补。

### （二）研究视角：范式之争与多元并存

1. **革命史范式 vs 现代化范式**：长期主导性范式是马克思主义"革命史范式"（以社会基本矛盾、阶级斗争为纲），20世纪80年代后"现代化范式"兴起与之争鸣，二者共同塑造了政治史、经济史的基本解释框架。
2. **全球史/跨国史视角**：近十年最显著的新取向。李翔明确主张"以全球史观深化中共抗战史研究"，强调"在世界发现中国历史"，把抗战置于世界反法西斯战争、国际共运、殖民地民族解放运动中理解。
3. **区域史三分格局**：根据地、国统区（大后方）、沦陷区三分的区域研究路径日益成熟，并与"整体史"取向结合。
4. **自下而下/日常生活史视角**：黄道炫主张"倾听静默的声音"，宋弘提出"革命日常史"，关注流亡迁徙、灾荒、民众负担、女性、观念等"沉默的大多数"。

**对比结论**：视角上呈现"宏观（全球史）—中观（区域/整体史）—微观（日常生活/情感史）"的多层叠加，传统宏大叙事与新文化史的"虚实结合"并存。

### （三）研究方法：从档案实证到跨学科与数字人文

1. **传统实证**：考据、辨伪、档案互证仍是基础，尤其依托县市档案馆开放与海外档案（日、美、英）发掘。
2. **跨学科**：政治学（政治文化）、社会学（集体记忆）、人类学（象征/仪式）、传播学（阅读/接受）、经济学（量化）等方法被系统引入。
3. **新文化史方法群**：记忆史、概念史、阅读史、情感史、物质文化史、身体史、空间史（李里峰系统梳理）。
4. **数字人文/量化历史**：大数据、AI技术开始进入抗战史（肖如平访谈指出"大数据和人工智能技术也开始运用于抗战史研究"）；华中师大等推进研究型量化数据库。

**对比结论**：方法论创新被视为"传统议题饱和、新材料空间收窄"之后的主要动力，学科交叉是未来持续创新的关键来源。

### （四）理论运用：从"主义"到"理论工具箱"

- **马克思主义唯物史观**仍是根本方法（李翔强调全球史观"不是取代"唯物史观）。
- **现代化理论**：与革命史范式长期对话。
- **全球史/跨国史理论**：成为最新理论增长点，强调本土与全球互动、跨国档案互证。
- **后现代/语言学转向下的新文化史理论**：记忆建构性、"历史一"与"历史二"（事实—表象）的辩证、概念史（科塞勒克）等。
- **环境史/生态史理论**：夏明方等倡导走出历史学学术圈，构建生态史学理论框架。

**对比结论**：理论运用呈"一元主导（唯物史观）+多元工具（全球史、新文化史、环境史、量化）"的格局，工具箱化特征明显。

### （五）研究结论：共识与分歧

**已形成的共识**：
- "十四年抗战"叙事与中国共产党抗战"中流砥柱作用"的系统论证；
- 正面战场与敌后战场"相互依存、缺一不可"；
- 中国战场是世界反法西斯战争"东方主战场"；
- 抗战是中华民族观念大普及、民族复兴转折点。

**仍存分歧/待深化**：
- 两个战场"主次"评价的历史表述仍需学理化；
- 国民党失败根源（通胀、腐败、土地问题）的因果链条仍有讨论空间；
- 战后处置（接收、审判、遣返、内战）与战时的衔接研究薄弱；
- 抗战记忆与"阶级创伤宏大叙事"的关系（高蕊等）仍有理论张力。

## 三、未来最有研究潜力的 2–3 个选题预测

综合上述"领域空白+方法前沿+史料可得性"三重标准，我预测以下三个选题最具潜力：

### 选题一：抗战时期"人"的日常生活、情感与身体史——微观与数字人文结合

**为什么最有潜力**：这是大陆与欧美学界共同的"最大公约数"。传统军事政治史饱和，而"普通人的战争经验"下沉方兴未艾；且日记、书信、笔记、照片、口述等民间文献近年大量出版，数字人文（文本挖掘、情感分析、空间可视化）为处理海量民间史料提供了新工具。

**研究空白**：流亡迁徙史、灾荒被难史、民众负担史、女性史、民众观念史、军人/干部/公务员/知识分子/在华西人的日常与情感，以及"战争的日常、革命的日常、非日常的日常"。

**建议切口**：以干部日记、知识分子书信、报刊读者来信为样本，做"情感史+阅读史"的量化与质性结合研究；或以口述史抢救性采集为基础，构建抗战个人生命史数据库。

**方法**：日常生活史、情感史、身体史 + 数字人文/量化 + 口述史。

### 选题二：战后处置与"跨越1945/1949"——受降、接收、审判、遣返与内战起源的跨国史研究

**为什么最有潜力**：这是公认的"研究空白"。学界对1945–1949年（受降接收、东京审判/南京审判、日侨俘遣返、国共谈判与内战爆发、金圆券与经济崩溃）的研究远不如战时充分，而李翔、肖如平等均明确指出"跨越1945""跨越1949"是重大未竟课题。它同时连接抗战与内战、中国与世界，理论空间大。

**研究空白**：经济接收的得失与"劫收"心理、审判中的中外互动、遣返中的人道与政治、内战爆发的社会经济根源（通胀、知识分子与公务员贫困化对政治抉择的影响）。

**建议切口**：以"接收—通胀—崩溃—内战"为因果链，做战后国民政府治理能力的长时段研究；或以东京审判/南京审判为个案，做国际法、舆论与记忆政治的跨国研究。

**方法**：全球史/跨国史 + 量化（物价、财政数据）+ 外交史/法律史。

### 选题三：全球史视野下的中共抗战与东亚殖民地民族解放运动的互动

**为什么最有潜力**：李翔明确指出，中共抗战史研究"依旧多是单向度的国内史叙述"，而抗战时期中共与周边国家共产党、亚洲殖民地半殖民地民族解放运动的互动，以及国际统一战线、华侨、国际友人宣传，是"有待国内外学界研究的重要问题"。这一选题天然要求多国档案互证，最能体现全球史观的方法论优势，也最易产出国际对话成果。

**研究空白**：中共与东南亚、南亚民族解放运动的联系；国际统一战线的运作机制；中共抗战经验的域外传播；华侨与华人华侨史的跨国维度。

**建议切口**：以某一具体中介（如国际友人、华侨组织、境外共产党）为线索，做中共与周边国家民族解放运动的互动史；或做中共敌后游击战与世界其他国家游击战的比较研究。

**方法**：全球史/跨国史 + 多国档案互证 + 比较研究 + 国际共运史视角。

**一句话总结**：中国学界1937–1949年研究已从军事政治史的"三分格局"走向"整体史+全球史+新文化史"的多元并进，共识（两战场、中流砥柱、东方主战场）与空白（战后处置、日常生活/情感、跨国互动）并存；未来最具潜力的三个选题分别是**日常生活/情感/身体史的数字人文研究**、**战后处置与"跨越1945/1949"的跨国史研究**、以及**全球史视野下的中共抗战与东亚民族解放运动互动研究**。
