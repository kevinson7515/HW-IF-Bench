# 钠离子电池正极来源摘记

- 层状氧化物：Fast-charge high-voltage layered cathodes for sodium-ion batteries，2024。O3 型 Na-Li-Ni-Mn-Ti 氧化物报告 260 Wh/kg（电极级）及全电池 700 圈后 80% 容量保持率。https://www.nature.com/articles/s41893-024-01266-1
- 聚阴离子复合路线：2025 年 EES，Na-rich 的 Na3.5V1.5Fe0.5(PO4)3 与 V2O3 双相共生，论文报告极长寿命工况；标题 100,000 圈是特定实验设定。这条摘记未记录完整的倍率、容量保持率和电池口径，需标注缺失。https://pubs.rsc.org/en-gb/content/articlehtml/2025/ee/d4ee05110f
- 普鲁士蓝类似物：2025 Nature Communications 研究将圆柱电池宽温循环与不可逆晶体结构变化关联，报告容量衰减随温度及循环条件变化。文中区分不同温度下电池测量和材料表征。https://www.nature.com/articles/s41467-025-57663-3
- 另一项 PBA 对照为水系钠离子电池，作者通过抑制析氢和析氧拓宽稳定电压窗口。水系结果与有机电解液全电池结果需要分别列示。https://doi.org/10.1021/acsanm.4c06180
